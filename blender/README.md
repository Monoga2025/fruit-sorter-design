# blender

Parametric Blender model of the lime sorter, with the same dimensions as the design report.

- `crear_maquina.py`: builds the machine from the report's parameters (in mm) and animates it. Run with `blender -b -P crear_maquina.py`; add `--anim` to render the mp4.
- `maquina_clasificadora.blend`: the generated scene.
- `maquina_funcionando.mp4` and `vista_cuadro_*.png`: the rendered animation and stills.
